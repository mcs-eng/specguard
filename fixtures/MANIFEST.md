## Planted discrepancies

### D-01 — Section A system voltage mismatch

- **Purpose:** The specification requires a 480V, 3-phase distribution switchboard. The submitted fictional Veylan Arcworks unit declares a 208V, 3-phase system.
- **Spec side:** `asterquay_learning_workshop_specification.pdf`, page **3**.
- **Spec quote:** `Provide a 480V, 3-phase distribution switchboard for service distribution.`
- **Cut-sheet side:** `veylan_arcworks_208v_switchboard.pdf`, page **1**.
- **Cut-sheet quote:** `Nominal system: 208V, 3-phase, 4-wire.`

### D-02 — Section B termination temperature mismatch

- **Purpose:** The specification requires 90 deg C minimum terminations. The fictional Torven cut sheet gives only 158 deg F, which converts to 70 deg C and is below the requirement. The cut sheet states the temperature rating in Fahrenheit only.
- **Spec side:** `asterquay_learning_workshop_specification.pdf`, page **5**.
- **Spec quote:** `Conductor terminations shall be rated 90 deg C minimum.`
- **Cut-sheet side:** `torven_70c_termination_switchboard.pdf`, page **2**.
- **Cut-sheet quote:** `Field conductor termination rating: 158 deg F.`

## Text-layer alteration

### T-01 — hidden spans on the altered Veylan cut sheet

- **Purpose:** Prove that the text-layer integrity screen in `specguard/integrity.py` detects text a reader cannot see, and that the runtime keeps such a document away from the model. This fixture exists to be caught.
- **Document:** `veylan_arcworks_208v_altered.pdf`, page **1**.
- **Method:** two spans written in PDF render mode 3, which paints nothing while text extraction still returns the characters. Both rendered pages are byte-identical to the unaltered Veylan cut sheet.
- **Hidden span 1:** `Nominal system: 209V, 3-phase, 4-wire.` It sits under the visible `Nominal system: 208V, 3-phase, 4-wire.` line and contradicts it.
- **Hidden span 2:** one sentence addressed to an automated reviewer. Its wording is deliberately not recorded here or in any other prose file; it lives in the fixture builder and in the fixture itself.
- **Expected screen result:** flagged page `[1]`, two hidden spans, and a quarantined run with no model call.

`tests/test_integrity.py` asserts this result. It also asserts that the four documents above produce zero flags, which is the false-positive check for the screen.

## Phase 7c messy fixture set

The two documents below form a separate evaluation lane. The specification names the selected fictional `Zarqelune Vantrel L-36` panelboard in Section 26 24 16; the package also contains the alternate `Zarqelune Vantrel L-18`, promotional pages, and administrative declarations. The seven planted mismatches are deliberately distributed across noisy sections and interior package tables. The two `N-*` cases are semantically compliant near-matches and must produce no finding.

### M-01 — fault-duty rating mismatch

- **Purpose:** The specification requires a 50 kA symmetrical fault-duty rating at 480 V; the selected product schedule states 42 kA at 480 V.
- **Spec side:** `nimbrin_thermal_annex_specification.pdf`, page **17**.
- **Spec quote:** `Provide a fault-duty rating of 50 kA symmetrical at 480 V.`
- **Cut-sheet side:** `zarqelune_vantrel_package.pdf`, page **6**.
- **Cut-sheet quote:** `42 kA symmetrical at 480 V`

### M-02 — terminal-temperature unit conversion mismatch

- **Purpose:** The specification requires 80 deg C minimum terminal insulation; 140 deg F converts to 60 deg C, so the package value is below the requirement. The specification quote is on the two-column page.
- **Spec side:** `nimbrin_thermal_annex_specification.pdf`, page **13**.
- **Spec quote:** `Terminal insulation shall be rated 80 deg C minimum for continuous service.`
- **Cut-sheet side:** `zarqelune_vantrel_package.pdf`, page **7**.
- **Cut-sheet quote:** `140 deg F (60 deg C)`

### M-03 — missing required listing

- **Purpose:** The specification requires the fictional QL-4 panelboard listing; the package declaration explicitly says that listing is not included.
- **Spec side:** `nimbrin_thermal_annex_specification.pdf`, page **18**.
- **Spec quote:** `Provide an assembly listed under the QL-4 panelboard listing.`
- **Cut-sheet side:** `zarqelune_vantrel_package.pdf`, page **10**.
- **Cut-sheet quote:** `Declared review marks: QF-2 factory review; QP-7 factory traceability; no QL-4 listing included.`

### M-04 — enclosure classification mismatch

- **Purpose:** The specification requires environmental classification E-4; the selected product construction table states E-2 indoor enclosure.
- **Spec side:** `nimbrin_thermal_annex_specification.pdf`, page **17**.
- **Spec quote:** `The enclosure shall carry environmental classification E-4.`
- **Cut-sheet side:** `zarqelune_vantrel_package.pdf`, page **9**.
- **Cut-sheet quote:** `E-2 indoor enclosure`

### M-05 — service-clearance dimensional conflict

- **Purpose:** The specification requires 1000 mm of clear working space in front of the panelboard; the dimensions table states that the selected product provides 760 mm. The row states a characteristic of the product as furnished, not vendor guidance, so the two statements cannot both hold.
- **Spec side:** `nimbrin_thermal_annex_specification.pdf`, page **18**.
- **Spec quote:** `Maintain 1000 mm clear working space in front of the selected panelboard.`
- **Cut-sheet side:** `zarqelune_vantrel_package.pdf`, page **8**.
- **Cut-sheet quote:** `760 mm provided`

### M-06 — spare-position quantity conflict

- **Purpose:** The specification requires three spare 20 A branch positions; the configuration table lists two positions.
- **Spec side:** `nimbrin_thermal_annex_specification.pdf`, page **18**.
- **Spec quote:** `Provide three spare 20 A branch positions for future circuits.`
- **Cut-sheet side:** `zarqelune_vantrel_package.pdf`, page **7**.
- **Cut-sheet quote:** `2 positions`

### M-07 — bus-material mismatch

- **Purpose:** The specification requires a copper main bus with a continuous tin-finished surface; the construction table states aluminum alloy with plated contact pads.
- **Spec side:** `nimbrin_thermal_annex_specification.pdf`, page **17**.
- **Spec quote:** `Main bus shall be copper with a continuous tin-finished surface.`
- **Cut-sheet side:** `zarqelune_vantrel_package.pdf`, page **9**.
- **Cut-sheet quote:** `aluminum alloy with plated contact pads`

### N-01 — compliant finish near-match

- **Purpose:** The specification says graphite gray and the package says graphite-grey baked coating. The wording differs, but the finish is compliant; this is a no-finding decoy.
- **Spec side:** `nimbrin_thermal_annex_specification.pdf`, page **17**.
- **Spec quote:** `The cabinet finish shall be graphite gray.`
- **Cut-sheet side:** `zarqelune_vantrel_package.pdf`, page **9**.
- **Cut-sheet quote:** `graphite-grey baked coating`

### N-02 — compliant control-supply near-match

- **Purpose:** The specification says 24 VDC and the package says 24-volt direct-current. The wording differs, but the control supply is compliant; this is a no-finding decoy.
- **Spec side:** `nimbrin_thermal_annex_specification.pdf`, page **13**.
- **Spec quote:** `Provide a 24 VDC control circuit for accessory indications.`
- **Cut-sheet side:** `zarqelune_vantrel_package.pdf`, page **7**.
- **Cut-sheet quote:** `24-volt direct-current`

It is a separate block because a decoy pair is not evidence of a discrepancy: it is the pair a correct run must **not** report. The two failures are different, and a reader who cannot tell them apart cannot tell a near-match error from an invention.
